# DEEP BLUE GRID エフェクト・スプライトシート

このディレクトリのSVGは、Web正本の
[`Renderer.ts`](../../canonical-source/Renderer.ts) に記述されたCanvas描画式を
256×256ピクセルの透明セルへ正規化したものです。背景、罫線、説明文字はシートへ
含めていません。

Unityでは、可能な限り同じ数式を使った手続き描画を優先してください。特にレーダーは
複数の非同期周期を重ねているため、有限枚の画像では完全な連続運動を再現できません。
PNG化したシートは、Shader/UI Graphicでの手続き描画が困難な場合の正確な静止サンプル兼
フォールバックです。

## 共通の切り出し規則

- 1セル: 256×256、原点は左上。
- フレーム番号は0始まり。横位置は `x = frame * 256`。
- 透明背景、sRGB、Straight Alphaを前提とします。
- Unity Texture Importer: Sprite Mode `Multiple`、Mesh Type `Full Rect`、
  Filter Mode `Point`、Wrap Mode `Clamp`、Mip Maps無効。
- Web正本は `imageSmoothingEnabled = false` です。
- 再生は先頭から末尾へ進み、末尾の次をフレーム0へ戻します。

## シート一覧

### `echo-8x1.svg`

- 8列×1行。
- 全セルで形状は同一。上下左右4方向だけを示す直線の腕と矢羽根、中央ハブです。
- `alpha = .55 + .3 * sin(t * 4)`
- 1周期: `2π / 4 = 1.570796秒`
- 8フレーム再生: 1枚あたり約196.350ミリ秒。
- 寸法: ハブ半径 `.075 cell`、腕先 `.28 cell`、矢羽根 `.085 cell`、
  線幅 `.045 cell`。

### `hit-sunk-pulses-8x2.svg`

- 8列×2行。
- 行0: HIT、`#ff8585`。
- 行1: SUNK、`#e5d78a`。
- `alpha = .7 + .25 * sin(t * 8)`
- 1周期: `2π / 8 = .785398秒`
- 8フレーム再生: 1枚あたり約98.175ミリ秒。
- 8頂点を45度刻みで結び、交互半径は`.27 cell`と`.16 cell`。

### `submarine-wake-shared-phase-12x1.svg`

- 12列×1行。
- `p = (t * 1.25) % 1`
- 各リング `q = (p + i * .42) % 1`、`i = 0, 1`
- 半径 `cell * (.13 + q * .34)`
- 不透明度 `.65 * (1 - q)`
- 線幅 `.035 cell`、色 `#7ce5df`。
- 1周期: `.8秒`、12フレームでは1枚あたり約66.667ミリ秒。
- 盤面上に複数の波紋が残っていても、個別の開始時刻を持たせず、全波紋へ同じ
  グローバルフレームを適用します。これがWeb正本の「同じリズム」です。

### `radar-contact-no-contact-12x2.svg`

- 12列×2行。各セルは2×2盤面領域を1枚へ収めています。
- 行0: CONTACT。黄 `rgba(229,215,138,.88)` の四隅ブラケットと破線円。
  主円半径 `baseCell * (.48 + .04 * sin(t * 4))` の1周期を12分割しています。
- CONTACTのブラケット不透明度は `.72 + .18 * sin(t * 3.4)`、
  外円不透明度は `.34 + .16 * sin(t * 4.6)`。3周期は非可換なので、
  スプライトのループ境界では補助的な明滅に小さな不連続が生じます。
- CONTACT主周期: `2π / 4 = 1.570796秒`、1枚約130.900ミリ秒。
- 行1: NO CONTACT。緑の四隅ブラケット、横方向グラデーションの走査線、
  破線の2×2外枠。
- 走査位置 `(.12 + ((t * .28) % 1) * .76) * 2 baseCells`。
- NO CONTACT周期: `1 / .28 = 3.571429秒`、1枚約297.619ミリ秒。
- 行ごとに再生速度が違います。厳密な一致には `Renderer.ts` と同じ手続き描画を
  使用してください。

### `target-vital-identification-pulses-8x4.svg`

- 8列×4行。
- 行0: 選択中の攻撃目標。`p = .5 + .5 * sin(t * 12)`、
  半径 `cell * (.22 + p * .18)`、不透明度 `.5 + p * .5`。
  1周期`.523599秒`、1枚約65.450ミリ秒。
- 行1: 未被弾の自軍重要区画。これは静止表示で、全8セルは同一です。
  外形`.17 cell`、45度回転、全体不透明度`.92`。
- 行2: 被弾済み重要区画。外形`.31 cell`、45度回転、
  `alpha = .78 + .2 * sin(t * 7)`。1周期`.897598秒`、
  1枚約112.200ミリ秒。
- 行3: 敵艦識別済みの菱形。外形`.34 cell`、45度回転、
  `alpha = .82 + .16 * sin(t * 5)`。1周期`1.256637秒`、
  1枚約157.080ミリ秒。
- 行3の艦種コード（CV/BB/CA/DD/DE/SS）は状態に応じた動的文字です。
  シートへ文字を焼き込まず、`#fff0b5`、太字monospace、サイズ`.18 cell`、
  中心から上へ`.35 cell`の位置へ別レイヤーで描画します。

## 色の出典

色は [`globals.css`](../../canonical-source/globals.css) の正本変数と
`Renderer.ts` のCanvas色指定に合わせています。

- Cyan: `#7ce5df`
- Danger: `#ff8585`
- Amber: `#e5d78a`
- Target: `#fff0be`
- Radar clear: `#60be9d`

SVG自体にアニメーション要素は入れていません。Unity側が選択中の行とフレームを
明示的に進めることで、休止・リトライ・画面切替時にもゲーム状態と同期できます。
