# DEEP BLUE GRID — Responsive UI QA Record

更新日: 2026-08-08
対象: Browser版。将来のUnity / Android比較基準

## 合格条件

- 横方向のページoverflowが0。
- 通常の配置・攻撃ループで、盤面と主操作が重ならない。
- iPhone縦持ち、タブレット縦持ち、PC横持ちは手動ページスクロールなし。
- 高さ600px以下の横持ちは一枚盤面＋右指揮卓とし、指揮卓を2列、操作高44px以上にする。
- MISSION一覧とLOGの長文だけは、専用領域内のスクロールを許可する。
- Browserのズームを禁止せず、Safe Areaを `viewport-fit=cover` と `env(safe-area-inset-*)` で守る。

## 2026-08-08 MISSION / TRAINING 再検証

Codex内蔵Browserで `320×568`、`402×874`、`568×320`、`844×390`、
`834×1112`、`1366×768` を再走査した。22件のMISSION一覧、6教程の
INITIAL TRAINING一覧、難易度、クリア状態、EXTREME、LEVIATHAN任務を
確認し、ページ横overflowはなし。狭い画面では一覧自身だけがスクロールし、
モード背面は固定される。訓練の誤指令は行動数と弾薬を消費しない。

### 2026-08-12 ライブラリ拡張の検証状態

現行データはMISSION 28件（戦術16・記録解析5・極限7）へ拡張済み。
Codex内蔵Browserでローカルproduction同等版を再走査した。320×568、
402×740、402×874、568×320、844×390、834×1112、1112×834、
1366×768、1536×864、1920×900で横overflowは0。配置・攻撃の主操作は
44px以上を維持し、横画面とタブレット縦画面はページscroll 0。短い縦画面は
盤面寸法を高さへ追従させ、402×740の配置はscroll 0、攻撃は自動位置合わせ後も
状態帯・戦術図切替・盤面・2段指揮卓を同時表示する。

402×874のMISSION一覧では16/5/7件の区分、難易度1～6、UNCLEARED/CLEARED
色分け、内部一覧scrollを確認。TRAINING 6教程、固定ブリーフ、CASUAL配置・攻撃、
PCの2盤面＋右指揮卓、SONAR音紋、CONTACT overlay、着弾後表示も基準画像へ保存した。

公開候補座標は `PLOTTED CONTACTS` として配置ブリーフ内に常設し、スマホの
短縮表示でも隠さない。状態名は `UNCLEARED` / `CLEARED`（教程は

## 視認確認

- 360×800と402×874では、作戦開始後の装飾mastheadを畳み、進行表示、状態帯、戦術図切替、盤面、下部卓を一画面に残した。
- 兵装ボタンは狭い画面だけ `GUN / F-4 / HARPOON / 8-INCH / MK-45 / SONAR` を表示する。詳細パネル、title、スクリーンリーダー名には正式名称を残す。
- 568×320と844×390では上部装飾、詳細文、常設LOGを畳む。LOG自体は切替帯の44pxボタンから開ける。
- 画面内の重要日本語を文字縮小だけで収めず、艦カード副文や長い説明の折畳みを優先した。

## 実戦フロー確認

- 402×874で通常砲撃の選択、照準、発射、敵行動、損害報告、`戦闘記録へ記載`、次の自軍行動までを通した。
- MISSION/TRAININGの縦画面配置卓は、状況資料を上段、指令限度と開始ボタンを下段左右へ分離し、開始ボタンが公開座標や指令表示へ重ならない構造に固定した。
- 損害報告中もページ寸法はviewport内に収まり、確認後は敵海域・通常砲撃選択へ戻り、不要な再スクロールは発生しなかった。
- LOGはページ全体ではなく一覧領域だけがスクロールする。表示直後のフォーカスは閉じるボタンへ移り、閉じた後は元の操作へ戻る。
- モード選択、MISSION一覧、LOG、結果画面はキーボードフォーカスをダイアログ内に保ち、`Escape` はMISSION一覧を閉じる。
